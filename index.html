8020IQ Problem-Solving Program

One path, four steps: learn the method, practice it on a case, apply it to a real client, and feed what you find back into the playbook. Follow the steps in order; the references below are there when you need a number or a term.

The path — follow in order

4 steps

This is the same sequence the program runs on. If you're new, start at step 1 and don't skip.

01 Learn · self-paced, ~60 min

Read the Problem-Solving Guide →

The McKinsey method taught through one running wholesale case: 7 steps in 4 phases, issue trees, MECE, the Pyramid Principle, SCR. This is the pre-work before Session 1 — at minimum read the 4 phases, Step 1, Step 2, and MECE.

McKinsey-Problem-Solving-Guide.html 02 Practice · Session 1, live, 90 min

Do the Training Program →

The flipped-classroom program: pre-work gate, the live case interview (run by a facilitator from the password-protected Interview Casefile), and certification levels. Submit the micro-exercise before class — no exercise, no seat.

8020IQ-Training-Program.html 03 Apply · post-work, async, real client

Diagnose a real client with the Playbook →

Route every Gross Lead or GNACC conversion decline to its common hypotheses, then run the channel-first diagnostic — Segment → Compare → Benchmark → Correlate → Prioritize — with tests and actions already mapped.

diagnostic-playbook.html 04 Deliver · Session 2, live, 45 min

Write the one-page SCR memo →

Recommendation first, Situation–Complication–Resolution, at most three exhibits. Presented in the two-minute elevator format and scored with the case rubric.

scr-memo-template.html

The loop closes here: every confirmed root cause from step 4 becomes a new hypothesis → test → action row in the playbook (step 3), so each cohort leaves it richer.
