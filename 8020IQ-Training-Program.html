The program

Five moves: read alone, solve together, apply on a real client, present the memo, feed the playbook.

Pre-work~60 min · solo

Learn the method

  • Read the Problem-Solving Guide — at minimum: the 4 phases, Step 1, Step 2, and MECE.
  • Micro-exercise (the gate): a client says "my cost per deal doubled." Write a SMART problem statement and a two-level MECE tree. Submit before class — no exercise, no seat.
Session 190 min · live

The case interview

  • 0–10 Warm-up: critique two problem statements, one vague, one SMART.
  • 10–55 Run a case from the Interview Casefile, interviewer-led. Pairs — one leads, one seconds; rotate each question.
  • 55–75 Debrief: map the case onto the 7 steps; show the rubric.
  • 75–90 Connect to reality: reproduce the baseline funnel and conversion math against the real benchmarks; use the case's $25K gross-profit assumption for dollar sizing, then map the diagnosis to the existing pillars.
Post-workasync · own book

A real client

Pick one underperforming client. Run the five-step diagnostic — Segment → Compare → Benchmark → Correlate → Prioritize — using the playbook. Deliverable: a one-page SCR memo, recommendation first, ≤ 3 exhibits.

Session 245 min · live

Memo review — and the harvest

Volunteers present in the two-minute elevator format; the group scores with the case rubric. Every confirmed root cause becomes a new playbook row — each cohort leaves the playbook richer.

Certification

  • Level 1 — Solver: completed a case as candidate + delivered an accepted SCR memo.
  • Level 2 — Interviewer: ran a case as facilitator. Interviewers facilitate the next cohort — the program staffs itself.

The Interview Casefile

Seven interviewer-led cases now span the funnel — with distinct root causes even when a stage repeats — each with an opening prompt, exhibits, expected answers, coaching lines, and rubric. Facilitators only: all seven are inside the encrypted casefile.

How to run a case

Interviewer-led. You control direction; provide exhibits only when asked. Time box 45–60 min. Coach with the scripted lines before improvising. Score 1–5 on the rubric during the case.
